# retro_rumble

Integrasi Force Feedback / Rumble dan Deteksi Event untuk game arcade (Daytona USA pada Sega Model 2 Emulator) berbasis modifikasi FFB Arcade Plugin.

## Fitur
- Deteksi event benturan / tabrakan (Crash trigger) untuk Daytona USA di Sega Model 2 Emulator.
- Console debugging otomatis (`AllocConsole`) saat emulator memuat plugin.
- Konfigurasi siap pakai untuk Model 2 Emulator (`FFBPlugin.ini`).
- Dukungan Force Feedback dan controller rumble.
